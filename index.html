Операторы ветвления

Операторы ветвления позволяют программе выбирать дальнейшие действия в зависимости от выполнения определённых условий. Благодаря им программа может реагировать на различные ситуации и выполнять разные последовательности команд.

Основные операторы ветвления

Оператор if

Оператор if является одной из основных конструкций ветвления. Он позволяет программе проверить определённое условие и выполнить заданный блок команд, если это условие является истинным. Таким образом, выполнение части программы становится зависимым от результата проверки. Если условие не выполняется, программа может просто пропустить данный блок и продолжить выполнение следующих команд.

Подробнее об операторе if

Условие в операторе if записывается внутри круглых скобок. Если результат проверки является истинным, выполняются команды, находящиеся внутри фигурных скобок.

Общий вид:

if (условие) {действие;}

Например, программа может проверить возраст пользователя и выполнить действие только в том случае, если возраст соответствует заданному условию.

Оператор if...else

Конструкция if...else используется, когда программе необходимо выбрать один из двух возможных вариантов действий. Сначала проверяется условие. Если оно истинно, выполняется первый блок команд. Если условие оказывается ложным, программа переходит к блоку else. Такая конструкция позволяет предусмотреть оба возможных результата проверки.

Подробнее об операторе if...else

В конструкции if...else предусмотрены два блока команд. Первый выполняется при истинном условии, а второй — если условие является ложным.

Общий вид:

if (условие) {действие 1;} else { действие 2; }

Например, можно проверить значение переменной и вывести один результат, если условие выполнено, или другой результат, если оно не выполнено.

Конструкция else if

Конструкция else if применяется в тех случаях, когда необходимо проверить несколько условий. Условия проверяются последовательно, одно за другим. Как только находится условие, которое является истинным, выполняется соответствующий ему блок команд. Такая конструкция позволяет программе выбирать один вариант из нескольких возможных.

Подробнее о конструкции else if

После первоначальной проверки с помощью if можно добавить несколько дополнительных условий с помощью else if. Они проверяются последовательно. Если ни одно из условий не выполняется, можно использовать блок else.

Общий вид:

if (условие 1) {действие 1;} else if (условие 2) { действие 2; } else { действие 3; }

Такая конструкция удобна, например, когда необходимо определить, к какой категории относится некоторое значение.

Оператор switch

Оператор switch используется для выбора одного из нескольких вариантов действий в зависимости от значения некоторого выражения. Вместо последовательной проверки большого количества условий можно перечислить возможные варианты с помощью конструкции case. Это делает код более удобным для восприятия в ситуациях, когда необходимо сравнить одно значение с несколькими возможными вариантами.

Подробнее об операторе switch

В конструкции switch каждый возможный вариант задаётся с помощью case. После выполнения нужного варианта обычно используется break, чтобы завершить выполнение конструкции. Если ни один вариант не подходит, может использоваться default.

Общий вид:

switch (значение) {

                case 1:
                    действие 1;
                    break;

                case 2:
                    действие 2;
                    break;

                default:
                    действие по умолчанию;
                }

Такая конструкция особенно удобна, когда одно значение необходимо сравнить с несколькими конкретными вариантами.
